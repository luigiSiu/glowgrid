# Photos

The main README has commented-out image tags waiting for these files. Drop a
photo in here with the matching name and uncomment the corresponding line in
`README.md` — nothing renders broken in the meantime.

Shoot in daylight where you can, and turn the panel brightness *down* before
photographing it: LEDs at full tilt blow out to white blobs on camera and lose
the shape of the icon entirely. Brightness 5-10 photographs far better than it
looks to the eye.

## Wanted

`hero.jpg` — the finished thing on your desk, panel lit with the green tick,
Mac somewhere in frame. This is the one people judge the project by, so it is
worth a few attempts.

`panel-states.jpg` — the four icons side by side (tick, cross, monitor, Z),
either as four photos stitched together or one panel photographed four times.
Proves at a glance what the thing actually does.

`wiring.jpg` — the three dupont leads going into `VIN`, `GND` and `D13`, close
enough to read the silkscreen. The single most useful photo for anyone
building one.

`connectors.jpg` — the back of the panel showing all three wire sets, so a
builder can tell the input from the output before they wire it backwards. Worth
annotating with arrows if you can be bothered.

`menu.png` — a screenshot of the app panel open in the menu bar. Use
`⇧⌘4` then Space to capture just the window with its shadow.
